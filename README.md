# 剧情规划器 (Plot Planner)

SillyTavern 第三方扩展：为文字角色扮演提供**独立大模型通道**的剧情编排工具。
规划类调用全部走插件自配的 API，不占用主对话连接，也不往主对话提示词里塞额外 token。

## 功能一览

| 模块 | 说明 |
|---|---|
| 世界书检索 | 导入酒馆原生 JSON 世界书或纯文本，关键词按需检索，只把命中条目喂给规划调用（这套世界书是插件自己的资料库：不接入酒馆原生世界书、不影响日常聊天，只在插件调模型时检索）；条目状态是三段式选择器：停用 / 关键词（最近对话里出现关键词才带出）/ 常驻（每次必带、不看关键词，对齐酒馆原生常驻；酒馆 JSON 的常驻标记导入时自动继承），既没关键词又不是常驻的条目导入时会提醒；「启用」按对话记忆：每个对话一套书单（存聊天文件），切换对话自动恢复各自的勾选，多世界多对话不用来回重勾；删书 / 删条目先进回收站（页面顶部入口，最多 30 条），可恢复或彻底删除，恢复的书各对话原有的启用勾选也随之恢复 |
| 记忆表格 | 对接「记忆增强表格」插件：原表库自动同步 + 备份（防高楼层数据清空）、一键「同步记忆表格」合并进镜像工作表（原版网格样式，行内容可编辑、「打标签」区维护自建词表与打标区域、词表标签可标「防重复」——事件类型标记，带标行在每次剧情规划时自动附带为「已发生的同类事件」并要求新剧情避免复刻同类事件的流程、按词表批量 AI 打标）、删除的行进独立的「已删除内容」页（内容不变不再出现，原表改动后重新出现待复审）、按标签与列召回注入规划 |
| 剧情指导（含随机事件、游戏玩法） | 分步规划向导：① 收集确认（本地检索材料、记忆表格两层筛选——先勾表格范围再按标签过滤，不勾标签则所选表全量召回；已隐藏楼层不计入上下文、游戏玩法勾选——默认勾当前生效条目随分析发送、预设勾选、剧情构思——记忆表格/玩法/预设这些勾选按对话记忆存聊天文件，同一对话下一轮规划回来不用重勾）→ ② 随机事件（大模型随机 / 事件库掷骰 / 自己给意见，可跳过）→ ③ 模型分析（OOC / 剧情重复 / 文风重复 / 进度 + 隐藏剧本设计）→ ④ 人工二检（打回重写 / 确认采用 / 不保存回第 1 步）。跳过随机事件会先停在「分析前确认」页核对材料再调模型。确认采用的规划存为「进行中剧情」（存聊天文件，刷新不丢）并自动绑定一条剧情注入（重新采用自动换内容、完结自动撤下，深度/角色可调），旧的自动归档历史，可一键「检查当前剧情」出执行报告（完成度 / 推进 / 文风 / OOC / 其他 / 建议，自动附带生效中的游戏玩法规则与路人反应卡以便对照执行情况）；标签词表与打标在「记忆表格」页维护，这里只做选择；「规划预设」（在「设置」页维护）可保存多条命名预设，勾选启用的按顺序追加进系统提示词。随机事件的掷骰入口只有向导第 2 步：先在勾选的掷骰板块——**事件条目** / **维度随机** / **AI 自主**——里按权重抽一个再走该板块（「参考事件库 / 顺带出预览剧情」可勾），选定向可作为材料融入规划、也可直接转隐身注入；页面下部是路人反应校准（模型从最近对话认出引人注目的事，材料在反应区「材料勾选」折叠里自行勾选——世界书按勾选的书检索，记忆表格/玩法/预设/进行中剧情按需附带，随对话记忆、独立于向导第 1 步，可填指导意见把控烈度与方向 → 显著性/即时口径/余波口径/底线/楼层预算的反应卡——一层 = 一条角色回复，到期自动撤下；生效期间规划与检查报告自动附带同一份口径）与「事件库设置」（掷骰板块开关与权重、维度、条目——概率/权重/冷却/触发关键词/轻重，轻＝一根针，重＝一个局）、「AI 建库」（出草稿勾选后导入，不参与掷骰）两个折叠区；最底部「游戏玩法」折叠区是游戏规则等一次性内容的条目库（常驻或按触发词自动注入主对话，触发词按最近几层对话匹配、扫描楼层数在本折叠区自行设置（0 = 不限），不必写成世界书；生效中的条目在向导第 1 步默认勾选，作为材料随规划分析一并发给模型，规划也按这些规则设计） |
| 联网搜索 | 设置页配置 Tavily 密钥，可输入关键词试搜验证；开启「分析前联网判断」后，「分析」与「检查当前剧情」前先由一次轻量判断（只发剧情简报）决定要不要联网——纯虚构剧情默认不检索，判「需要」（真实历史/地域/机构/行业运作、时效信息等写错会露馅的现实细节）才按模型给的关键词直查 Tavily（搜索本身不耗模型 token），结果作为「联网检索纪要」附进材料 |

幕后内容（确认采用的规划、选定向的随机事件、路人反应卡）一律以**隐身注入**生效：模型能看到、聊天界面不显示；剧情注入随「结束剧情」自动撤下，带层数的到期自动撤下。生效中的注入统一在**设置页底部**「生效中的隐身注入」里查看、提前撤下或删除。

## 安装

### 从 GitHub 安装

1. 酒馆顶栏「扩展」图标 → 扩展面板 → **Install extension**
2. 粘贴仓库地址 `https://github.com/nid1604436054-ops/st-plot-planner` → 安装 → 在列表中启用「剧情规划器」

### 本地开发安装

把本文件夹（或做 junction / 符号链接）放到：

```
SillyTavern/public/scripts/extensions/third-party/st-plot-planner/
```

重启酒馆，在扩展面板中启用。

## 快速上手

1. 魔法棒菜单 → **剧情规划器** → **设置**页签：填 API 地址 / 密钥（OpenAI 兼容），点「获取模型列表」在下拉框选模型，再点「测试连接」；用推理模型时若报「空内容且 finish_reason=length」，到高级设置勾**关闭思考**
2. 打开剧情规划器 → **世界书**：导入酒馆 JSON 或纯文本 → 「检索测试」验证命中
3. **剧情指导**：「开始规划」走分步向导（收集确认 → 随机事件 → 分析前确认 → 模型分析 → 人工二检），「确认采用」存为进行中剧情并自动注入；之后随时「检查当前剧情」看执行报告；页面下部还有「路人反应校准」「事件库设置 / AI 建库」与「游戏玩法」折叠区
4. **游戏玩法**（剧情指导页最底部折叠区）：添加游戏规则等条目，常驻或按触发词自动注入主对话；生效中的条目在向导第 1 步默认勾选，随规划分析一起发给模型

## 兼容性

- SillyTavern 1.15.0 实测通过；酒馆内部模块一律用绝对路径导入（`/script.js`、`/scripts/extensions.js`），更低版本未测试
- 纯前端 ES Module，零构建、无第三方依赖
- 所配 API 服务商需支持浏览器跨域（CORS）；遇到 CORS 问题时更换支持跨域的服务商 / 中转 / 本地网关

## 安全说明

API 密钥保存在酒馆设置中（浏览器端 + 服务器 settings.json），仅用于本插件发出的请求；
隐身注入的正文同样保存在设置里，重置/导出设置时会一并带出，请注意。
