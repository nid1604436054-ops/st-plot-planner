# 剧情规划器 (Plot Planner)

SillyTavern 第三方扩展：为文字角色扮演提供**独立大模型通道**的剧情编排工具。
规划类调用全部走插件自配的 API，不占用主对话连接，也不往主对话提示词里塞额外 token。

## 功能一览

| 模块 | 说明 |
|---|---|
| 世界书检索 | 导入酒馆原生 JSON 世界书或纯文本，关键词按需检索，只把命中条目喂给规划调用（这套世界书是插件自己的资料库：不接入酒馆原生世界书、不影响日常聊天，只在插件调模型时检索）；条目状态是三段式选择器：停用 / 关键词（最近对话里出现关键词才带出）/ 常驻（每次必带、不看关键词，对齐酒馆原生常驻；酒馆 JSON 的常驻标记导入时自动继承），既没关键词又不是常驻的条目导入时会提醒；「启用」按对话记忆：每个对话一套书单（按对话各自保存），切换对话自动恢复各自的勾选，多世界多对话不用来回重勾；删书 / 删条目先进回收站（页面顶部入口，最多 30 条），可恢复或彻底删除，恢复的书各对话原有的启用勾选也随之恢复。三段式之外另有**「世界书自选」**（规划向导第 1 步的悬浮面板）：按书分组勾条目，勾中的**整条原文**随规划分析进材料——性知识/世界观口径这类「照着写」的材料每次都该在场，三段式（关键词碰运气、常驻进插件全部调用不能按次控制）伺候不了；不看关键词/常驻/书与条目的启用状态（勾选是唯一口径，禁用的照样能勾），与检索命中自动去重（自选优先，同一条不进材料两次），勾选随对话记忆保存、无冷却 |
| 知识库 | 自建素材清单，**反模型偏好**用——模型在「约会去哪、消费什么」这类选择上有训练分布尖峰，换模型重 roll 也只在几个常见选项里打转；清单把候选集合整个换掉。清单只喂**剧情规划向导**（随机事件、路人反应与扮演模型注入不碰知识库），条目全局共享（不绑聊天不绑角色）。每张清单**自定义表头**（字段名任意定，如「名字、说明、标签」只是其中一种）——表头在新建时定死、**永不做事后迁移**：换表头＝新建清单重导，原始文本在手重导即重建。内容生产流程＝在外部用提示词批量起草 → 粘贴进「导入」区 → 选主连接或供应商方案（单次选用）让模型照表头结构化 → 草稿逐条审改、勾选入库（「入库选中/丢弃草稿」在草稿页头部，不用翻到内容最下面）；**长草稿自动分批**整理（一批一次调用，防止单次回复太长被截断出错；个别批失败不拖垮其余，报错带问题所在），**粘贴的原文与结构化草稿都随页面保留**（刷新不丢，入库或丢弃才清）；条目浏览是紧凑一行一条＋搜索＋标签筛选（标签筛选认表头里名字含「标签」的字段），可手动添加（新条目插到列表最上面）、编辑、删除，冷却中的条目带徽章显示。页签布局：「素材清单」标题常驻在灰底区块之外（与清单行拉开区分），「新建清单」在页顶**默认收起，点「新建清单」才展开表单**（投喂方式的选择随会话记住，创建成功自动收起）；清单行单行紧凑——点行或行首箭头展开/收起条目（「改名」与清单名同行），**展开区就在自家清单行正下方**，条目列表自带滚动条原地翻看，「导入」入口在展开后的条目区工具行。抓取在剧情指导页第 1 步：勾选清单（随对话记忆保存）→「知识库抓取」悬浮面板（**面板里按清单做折叠栏：抽样清单默认展开、全量清单默认折叠**——全量整表本来就要发不用逐条过目，要踢谁再展开；折叠只动显示不动发送集）。每张清单一个**投喂方式**（新建时二选一、清单展开区随时可改）：**抽样**（默认）＝按**轮换**随机抓一小把（默认 5 条，设置可调；整张清单洗牌按序发、**全部条目各发一次之前不重复**、发完一轮自动重洗开新一轮；无语境过滤；冷却中的条目本轮跳过、下轮回归；一轮剩余不足有多少抓多少；清单行显示「本轮剩 N」进度，轮换队列全局共享跨聊天），抓到的条目看得见：**每张抽样清单各自的「采用方式」二选一——「全部采用」（默认）＝整把发给规划模型让它自己挑着用（随机抓一把让模型挑是主用法）；「自选」＝你勾哪条发哪条，这张清单一条不勾＝它本次不带材料、别的清单不受影响**（方式与勾选随向导留底，「放弃保存」后同样保留——回第 1 步可直接原班材料再次分析）、单条可踢（不补抓）、每张清单可整把换新（重抓＝按队发下一批，丢掉的要等下一轮）；**全量**＝整表可用条目全部随分析发给模型挑（礼物这类「整张候选表都该在场」的清单）——不抓取不重抓、不占轮换队列，面板显示「全量 N 条·约 X 字」，单条可踢（踢＝本次不发，可还原），冷却中的条目自动跳过；发给模型的口径也按投喂方式分组：**全量＝硬口径**（规划凡涉及这类内容必须从中选、不得自拟同类），**抽样＝软口径**（优先从中选用，没覆盖的方向可以自拟）。发送的随材料进第 2 步确认页**按清单点名**（全量清单只报「全量 N 条」不逐条列编号；勾了清单却 0 条发送的——自选一条没勾、还没抓、全冷却——标 ⚠ 点名并给回第 1 步的指引，不再无声缺席）；规划生成在 JSON 里**自报选用了哪些条目**，选用过的进**冷却**——结算在**确认采用或转隐身注入时**（规划真正上场才算用过：草稿放弃、重新生成都不碰冷却；按采用次数计，默认 3 次提案值、设置可调），防「模型从小把里连挑最熟那条」；冷却中的条目在「知识库」页**点冷却徽章可立即清零**（徽章显示剩余次数） |
| 记忆表格 | 对接「记忆增强表格」插件：原表库自动同步 + 备份（防高楼层数据清空）、一键「同步记忆表格」合并进镜像工作表（原版网格样式，行内容可编辑、「打标签」区维护自建词表与打标区域、按词表批量 AI 打标——一行可同时命中多个标签，符合即打、是否符合由模型按词表注释自判；召回的记忆行行尾自带标签，规划提示词写明已有多条同标签/同类型事件时新规划不得复刻其流程——同类型可以有、走向须有新意）、删除的行进独立的「已删除内容」页（内容不变不再出现，原表改动后重新出现待复审）、按标签与列召回注入规划；镜像区顶部可**按标签检索行**（输入标签名部分字样，只列出打了该标签的行，右侧显示命中统计）；镜像分组标题悬浮说明边界——**镜像只喂本插件的规划与检查，主对话模型看的是原表**（在镜像里删行不影响扮演侧的记忆，要修扮演侧事实去源插件改） |
| 剧情指导（含随机事件、路人反应、游戏玩法） | 三步规划向导：① 材料（本地检索材料、记忆表格两层筛选——先勾表格范围再按标签过滤，不勾标签则所选表全量召回；已隐藏楼层不计入上下文；游戏玩法勾选——默认勾当前生效条目随分析发送；知识库清单勾选——「知识库抓取」悬浮面板：抽样清单按轮换随机抓一小把（一轮内不重复），抓到的单条可踢、整把可换新；全量清单整表随行、单条可踢可还原（见「知识库」行）；「世界书自选」悬浮面板——按书勾条目（**书默认折叠、要勾时点「展开」；搜检索词时命中的书自动展开；条目行只显示名字，原文整条在悬浮提示里看**）、勾中的整条原文随分析（见「世界书检索」行）；随机事件 / 路人反应两个工具入口；剧情构思与修改意见——里面的**点名要求都是硬要求**（数量、价位金额、时间日期、由谁发起或挑选、地点、身份资格，点名了就逐条落实、不打折不反着写；数量没点名时用设置里的「规划节点下限」兜底，默认 5 不设上限）；记忆表格/玩法/知识库清单/世界书自选这些勾选按对话记忆保存，同一对话下一轮规划回来不用重勾）→ ② 确认（分析前逐行核对：插入单元的名单、玩法条目名单、知识库条目分组名单、自选世界书名单、联网搜索开关——材料细账第 1 步已确认过，此处不重复）→ ③ 结果（人工二检：**时间基准**行——模型从材料里读出的「现在」（如「当天上午」）原样上屏，排程全以它为锚、读错一眼可辨，也随规划文本首行一并注入给扮演模型；**第二遍对齐修改**行——默认两遍调用的第二遍（见下）改了什么逐条列在同一张卡，采用的已是修正后版本；检查结果之外多一道 **user 编排黄牌**——本地粗扫规划文本里疑似「替 user 做动作/说台词/把 user 建库、联网判断）都会把启用中的按顺序拼进系统提示词末尾，开关只有设置页这一处。页面下部是「事件库设置」（掷骰板块开关与权重、维度、条目——概率/权重/冷却/触发关键词/轻重，轻＝一根针，重＝一个局）与「AI 建库」（出草稿勾选后导入，不参与掷骰）两个折叠区；最底部「游戏玩法」折叠区是游戏规则等一次性内容的条目库（常驻或按触发词自动注入主对话，触发词按最近几层对话匹配、扫描楼层数在本折叠区自行设置（0 = 不限），不必写成世界书；条目可**就地编辑**，保存后立即按新参数重扫注入；生效中的条目在向导第 1 步默认勾选，作为材料随规划分析一并发给模型，规划也按这些规则设计）；游戏玩法再往下是「生效中的隐身注入」折叠区（本插件产生的注入在这里统一查看、停用或删除提前撤下）——这些底部工具区只在空闲页与第 1 步显示，进入确认/结果等运行页自动让位。向导页首常驻 **①②③ 步骤跳转条**：随时切到任意一步，已填内容与生成结果全保留（第 ③ 步是空白二检页，可直接往规划框里填字看排版；分析在途时点 ② 回实时输出页）；向导进度**自动留底**——刷新页面后回到离开的那一步，已生成未处理的规划停在第 ③ 步等操作，确认采用或取消后才清空 |
| 联网搜索 | 设置页配置 Tavily 密钥，可输入关键词试搜验证；两个开关——「启用联网搜索」是总开关（关 = 完全不联网，只留手动试搜），「模型搜索前判断」定口径：开着时「分析」与「检查当前剧情」前先由一次轻量判断（只发剧情简报）决定要不要联网——纯虚构剧情默认不检索，判「需要」（真实历史/地域/机构/行业运作、时效信息等写错会露馅的现实细节）才按模型给的关键词直查 Tavily（搜索本身不耗模型 token）；关掉判断则只要总开关开着，每次分析/检查都直接检索（轻量调用只为取关键词），结果作为「联网检索纪要」附进材料 |
| 数据备份与搬家 | 各对话的插件数据（记忆表格镜像、剧情档案、各类勾选、书单）存在插件自己的双层存储里（浏览器热层 + 酒馆设置文件留底），**不写进聊天文件**——几千层的大聊天也不会因为插件保存而卡顿。设置页「数据备份与搬家」：导出备份成 JSON 存到任意位置（换电脑/重装酒馆的救命备份）、导入备份恢复、备份继承——把别的聊天的数据继承给当前聊天（旧聊天太卡换新聊天、开分支、聊天改名后找回数据都靠它） |

幕后内容（确认采用的规划、选定向的随机事件、路人反应卡）一律以**隐身注入**生效：模型能看到、聊天界面不显示；剧情注入随「结束剧情」自动撤下，带层数的按**聊天楼层净增**到期自动撤下（一层＝一条角色回复，user 楼不计；滑动 / 重新生成只是替换最后一条回复，不消耗层数）。生效中的注入统一在**剧情指导页底部**（游戏玩法折叠区下方）的「生效中的隐身注入」里查看、提前撤下或删除。

面板顶部标题旁有**缩放按钮（− / ％ / ＋）**：整个面板内容等比放大缩小（80%–160%，点百分比数字恢复 100%，随设置保存），放大后页面相应变长；记忆表格的表格放不下时，滚轮悬在表格上可直接左右翻看。

## 安装

### 从 GitHub 安装

1. 酒馆顶栏「扩展」图标 → 扩展面板 → **Install extension**
2. 粘贴仓库地址 `https://github.com/nid1604436054-ops/st-plot-planner` → 安装 → 在列表中启用「剧情规划器」

### 本地开发安装

把本文件夹（或做 junction / 符号链接）放到：

```
SillyTavern/public/scripts/extensions/third-party/st-plot-planner/
```

重启酒馆，在扩展面板中启用。

## 快速上手

1. 魔法棒菜单 → **剧情规划器** → **设置**页签：填 API 地址 / 密钥（OpenAI 兼容；密钥框右侧小眼睛可显示原文核对），点「获取模型列表」在下拉框选模型，再点「测试连接」；用推理模型时到高级设置勾**关闭思考**（带上 deepseek/GLM/Qwen/OpenAI/vLLM 各家的关闭参数；端点报错不认哪个参数就自动去掉哪个重发，不再一刀全丢放任思考回来；即便思考仍被写进正文——输出开头出现「## 思考（Thinking）」类标头——调用层也会自动掐断重试一次）；规划默认**两遍调用**（第一遍生成＋第二遍对齐修改；两遍提示词开头相同，支持前缀缓存的服务商第二遍输入大部分走约一折缓存价、整体约 ×1.2～1.4，不做缓存的服务商接近 ×2），要省 token 可在高级设置关掉「生成后对齐修改（第二遍）」
2. 打开剧情规划器 → **世界书**：导入酒馆 JSON 或纯文本 → 「检索测试」验证命中
3. **剧情指导**：「开始规划」走三步向导（① 材料 → ② 确认 → ③ 结果）；随机事件 / 路人反应在第 1 步的入口键点开悬浮面板取用（产物为「单元」，暂存最多各 3 个）；「确认采用」存为进行中剧情并自动注入；之后随时「检查当前剧情」看执行报告；页面下部还有「事件库设置 / AI 建库」与「游戏玩法」折叠区
4. **游戏玩法**（剧情指导页最底部折叠区）：添加游戏规则等条目，常驻或按触发词自动注入主对话；生效中的条目在向导第 1 步默认勾选，随规划分析一起发给模型

## 兼容性

- SillyTavern 1.15.0 实测通过；酒馆内部模块一律用绝对路径导入（`/script.js`、`/scripts/extensions.js`），更低版本未测试
- 纯前端 ES Module，零构建、无第三方依赖
- 所配 API 服务商需支持浏览器跨域（CORS）；遇到 CORS 问题时更换支持跨域的服务商 / 中转 / 本地网关

## 安全说明

API 密钥保存在酒馆设置中（浏览器端 + 服务器 settings.json），仅用于本插件发出的请求；
隐身注入的正文同样保存在设置里，重置/导出设置时会一并带出，请注意。
