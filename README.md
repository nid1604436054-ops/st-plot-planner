# 剧情规划器 (Plot Planner)

SillyTavern 第三方扩展：为文字角色扮演提供**独立大模型通道**的剧情编排工具。
规划类调用全部走插件自配的 API，不占用主对话连接，也不往主对话提示词里塞额外 token。

## 功能一览

| 模块 | 说明 |
|---|---|
| 世界书检索 | 导入酒馆原生 JSON 世界书或纯文本，关键词/正则按需检索，只把命中条目喂给规划调用 |
| 记忆表格 | 对接「记忆增强表格」插件：原表库自动同步 + 备份（防高楼层数据清空）、一键「同步记忆表格」合并进镜像工作表（原版网格样式，行内容可编辑、智能归类自动打标签）、删除的行进独立的「已删除内容」页（内容不变不再出现，原表改动后重新出现待复审）、按标签与列召回注入规划 |
| 剧情指导 | 分步规划向导：① 收集确认（本地检索材料、预设临时勾选、记忆表格标签匹配、剧情构思）→ ② 随机事件闸口（大模型随机 / 事件库掷骰 / 自己给意见，可跳过）→ ③ 模型分析（OOC / 剧情重复 / 文风重复 / 进度 + 隐藏剧本设计）→ ④ 人工二检（打回重写 / 确认采用 / 不保存回第 1 步）。跳过随机事件会先停在「分析前确认」页核对材料再调模型。确认采用的规划存为「进行中剧情」（存聊天文件，刷新不丢）并自动绑定一条剧情注入（重新采用自动换内容、完结自动撤下，深度/角色可调），旧的自动归档历史，可一键「检查当前剧情」出执行报告（完成度 / 推进 / 文风 / OOC / 其他 / 建议）；「匹配设置」维护标签词表与打标区域，用词表给记忆表格批量打标签后按标签召回（不匹配则全量召回），召回的记忆行用于查重与推新；「规划预设」可保存多条命名预设，勾选启用的按顺序追加进系统提示词 |
| 随机事件 | 「走在路上」式的动态遭遇生成，按概率/权重掷骰，生成可选走向并转为幕后注入 |
| 隐身注入 | 双模式幕后提示词注入：明盘（你审核过、界面不显示）/ 密封（AI 生成、你自己也看不到内容，如对手手牌） |
| 储存空间 | 游戏规则等一次性内容的条目库，按触发词自动注入，不必专门写成世界书 |

## 安装

### 从 GitHub 安装

1. 酒馆顶栏「扩展」图标 → 扩展面板 → **Install extension**
2. 粘贴仓库地址 `https://github.com/nid1604436054-ops/st-plot-planner` → 安装 → 在列表中启用「剧情规划器」

### 本地开发安装

把本文件夹（或做 junction / 符号链接）放到：

```
SillyTavern/public/scripts/extensions/third-party/st-plot-planner/
```

重启酒馆，在扩展面板中启用。

## 快速上手

1. 魔法棒菜单 → **剧情规划器** → **设置**页签：填 API 地址 / 密钥（OpenAI 兼容），点「获取模型列表」在下拉框选模型，再点「测试连接」
2. 打开剧情规划器 → **世界书**：导入酒馆 JSON 或纯文本 → 「检索测试」验证命中
3. **剧情指导**：「开始规划」走分步向导（收集确认 → 随机事件闸口 → 分析前确认 → 模型分析 → 人工二检），「确认采用」存为进行中剧情并自动注入；之后随时「检查当前剧情」看执行报告
4. **隐身注入**：可新建明盘（自己可见）或密封（AI 生成、自己也不可见）注入
5. **储存空间**：添加游戏规则等条目，按触发词自动注入主对话

## 兼容性

- SillyTavern 1.15.0 实测通过；酒馆内部模块一律用绝对路径导入（`/script.js`、`/scripts/extensions.js`），更低版本未测试
- 纯前端 ES Module，零构建、无第三方依赖
- 所配 API 服务商需支持浏览器跨域（CORS）；遇到 CORS 问题时更换支持跨域的服务商 / 中转 / 本地网关

## 安全说明

API 密钥保存在酒馆设置中（浏览器端 + 服务器 settings.json），仅用于本插件发出的请求；
密封注入的内容也保存在设置里，重置/导出设置时会一并带出，请注意。
