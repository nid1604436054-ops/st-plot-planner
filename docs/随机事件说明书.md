# 随机事件 · 使用说明书

对应版本：T2 单元制落地之后（随机事件 / 路人反应改为向导第 1 步入口键 + 悬浮面板，产物统一为「单元」）。界面文案以扩展实际显示为准，本文解释每个部分的含义与行为。

## 0. 这块区域是什么

随机事件已并入「剧情指导」页，**入口只有一处：分步规划向导第 1 步的「随机事件」入口键**（点开悬浮面板，大模型随机 / 掷骰出草稿点「立为单元」、自己写意见立单元都在里面）。路人反应同样是第 1 步的入口键（见第 5 节），不再占页面下部的板块。两个工具的产物统一叫**单元**：暂存在各自面板里（每工具最多 3 个），入池后在第 1 步「插入单元」勾选随分析发送、可转隐身注入、可被对方工具导入再加工（导入是两工具间唯一影响通道）。向导之外，「剧情指导」页下部保留三块不与向导重复的东西：

| 部分 | 一句话定位 |
|---|---|
| 事件库设置（折叠区） | 掷骰的弹药库与调度台：板块开关与权重 + 事件条目 + 事件维度 |
| AI 建库（独立折叠区） | 让模型按维度批量出条目草稿，勾选后导入事件库 |
| 游戏玩法（折叠区） | 游戏规则等一次性内容的条目库，常驻或按触发词注入主对话 |

「事件库设置」折叠区内部（底部，默认收起）：

| 部分 | 一句话定位 |
|---|---|
| 掷骰板块开关 | 三个掷骰入口的并行调度：事件条目 / 维度随机 / AI 自主，勾选=参与掷骰，旁边数字=权重 |
| 事件条目 | 血肉：具体的事件库，每条带概率 / 权重 / 冷却 / 轻重 / 触发关键词 |
| 事件维度 | 骨架：事件分成哪几类；维度随机按权重抽方向，AI 自主从清单里挑 |

「AI 建库」是**另一个独立折叠区**（不参与掷骰）：让模型按维度批量出条目草稿，勾选后导入事件库。它只是填库工具，和掷骰的可能性计算完全无关。

三个掷骰板块的分工：**事件条目**＝你要库里策划好的事（最可控）；**维度随机**＝随机抽个方向即兴（探索和惊喜）；**AI 自主**＝模型看着当前剧情自己挑最贴合的维度（要「合适」而不是「随机」）。路人反应是反应性校准，和随机事件互补：随机事件是「主动制造的意外」，路人反应是「已有行动的后果校准」。

## 1. 随机事件工具面板（第 1 步入口键点开，掷骰唯一入口）

第 1 步点「随机事件」入口键打开悬浮面板（按钮带暂存计数）。面板从上到下：一个勾选——**参考事件库**（掷到「维度随机」或用「大模型随机」时把事件库条目列给模型参考，可从中选方向也可另起）；三个动作键——**大模型随机**（不经掷骰直接即兴）、**掷骰**（按底部掷骰板块权重走管线，见 1.2）、**清空暂存**（清掉随机事件名下全部单元，路人反应的不动）；**导入路人反应单元做参考**（对方暂存里「加工史还没本工具」的才能勾）；状态行、暂存池与草稿区；面板最底部是**或自己给意见**（写下想法点「立为单元」直接入池）。大模型随机与掷骰的产物先以**草稿**出现在池顶——点草稿上的「立为单元」才收进暂存池（不用写意见，生成本身就是内容；再生成一次会换掉草稿），入池后每工具 ≤3、满了禁生成先删一个。**入池单元不会自动进规划**——在向导第 1 步入口键下方的「插入单元」勾选区决定哪些随分析发送（参不参与规划是规划侧的事，卡上没有这个开关）。

### 1.1 掷骰板块与权重

- 位置在底部「事件库设置」折叠区的最顶部：三行「勾选框 + 板块名 + 权重数字框」，勾选=该板块参与掷骰，旁边数字=板块权重（越大越容易被掷到），改动即保存。
- 三个板块：**事件条目**（从事件库抽一条策划好的）、**维度随机**（随机抽维度即兴）、**AI 自主**（把维度清单交给模型，它挑最贴合当前剧情的）。
- 每次掷骰第一步：在勾选且有货的板块里按权重抽一个，抽中谁就走谁。没勾选、或没货的板块（比如条目全在冷却、维度全停用）自动退出本轮。
- 默认值：条目 6 / 随机 4 / AI 自主 2（AI 自主默认不勾选，想要时勾上即可；从旧版「事件库占比 60%」升级会自动换算成 6:4，掷骰口味不变）。
- 板块权重全填 0 时等机会抽；只勾一个板块 = 每次都走它。

### 1.2 掷骰按钮按下后的完整流程

1. **维度检查**：一个启用的维度都没有 → 直接提示「本次未掷出事件（没有启用的维度）」，不花任何调用。
2. **密度规则**：查看最近两次掷骰记录，若都是同一维度，本次掷骰暂停该维度（三个板块都避开它）；没有别的维度可选时忽略此规则。
3. **条目过滤**（候选资格）：条目启用 + 所属维度启用 + 不在冷却中 + 触发关键词命中（若填了关键词）。
4. **板块抽取**：在勾选且有货的板块（事件条目 / 维度随机 / AI 自主）里按板块权重抽一个；全都没勾或都没货 → 提示「没有可用的掷骰板块」。
5. **走事件条目**：合格条目按「权重 × 触发概率」加权抽一条——概率只影响相对命中率，掷骰必出事件，不会空手。
6. **走维度随机**：在启用维度里按「维度权重」加权抽一个方向，让模型按该维度的气质即兴。
7. **走 AI 自主**：把启用维度清单（密度暂停的已剔除）交给模型，由它结合当前剧情挑一个最贴合的，按该维度气质即兴。挑选和生成在同一次调用里完成，不额外花调用。
8. **生成调用**（一次规划通道调用，三板块与大模型随机相同）：材料＝**第 1 步确认的同一套**（记忆表格档位与标签、游戏玩法勾选、世界书命中、进行中剧情）+ 角色设定摘要 + 最近对话（设置页「规划携带层数」，默认 30，0=全部；已隐藏楼层不计入）+ 最近出过的事件标题（防重复）+ 底线条款 + 事件方向（条目：维度/条目名/方向提示/轻重口径；随机：维度名 + 方向提示；AI 自主：整张维度清单）；勾了导入单元的再附「导入单元」小节（对方工具的暂存产物，仅作参考材料，不是既成事实）。
9. **落账**：生成成功后才记账——掷中的条目从当前楼层起算冷却；写入「最近事件」列表（最多 12 条；AI 自主记下它选中的维度，同样受密度规则约束）。生成失败不烧冷却。

### 1.3 状态行与事件单元卡

- 状态行显示来源：「来自事件库『xxx』」「来自维度『xx』自由生成」「来自 AI 自主·维度『xx』」，或未掷出的原因；生成后提示点「立为单元」收进暂存（再生成会换掉草稿）。
- **草稿卡**（大模型随机/掷骰刚生成、还没入池）：带「草稿」标记，走向照常可点选定向；动作只有两个——**立为单元**（收进暂存池，之后在第 1 步「插入单元」勾选随分析发送）与**丢弃**（只丢草稿，不动暂存池）。
- 单元卡（已入池）：卡头两个小标＝**加工史**（左＝先、右＝后，一字标「事 / 反」，没经过的留空位对齐）+ 标题 + 描述 + 约 3 个可选走向。
  - **点一个走向** → 选定（再点一次取消）。选定即「定向」：随分析发送的材料与转注入的正文都用它。
  - **转为隐身注入**：需先选定走向；深度 4、system 角色、仅当前聊天，**注入层数可填（1–200，默认 20）**，按聊天楼层净增到期自动撤下（剧情指导页底部「生效中的隐身注入」折叠区可提前撤下）；不经过分析，也不影响这个单元在第 1 步「插入单元」的勾选。
  - **垃圾桶**：从暂存池删除（已转隐身注入的不受影响）。
  - **不选走向**也完全可以：单元只作参考，不注入不产生任何后续。

## 2. 事件维度（设置区折叠板块）

### 2.1 每行控件

- **启用**：取消勾选 = 该维度整体下线（它的条目不参与掷骰，维度随机和 AI 自主也不选它）。
- **维度名**（加粗显示）。
- 概要行：权重数字 + 方向提示前 60 字。
- **编辑 / 收起**：展开编辑器。
- **垃圾桶**：删除维度。**条目不会被删**，只会变成「未分组」（未分组条目不参与掷骰，可在条目编辑器里挂回其他维度）。

### 2.2 编辑器（展开后）

- **维度名**：即时保存。
- **权重**：维度随机板块的抽中占比（和别的维度比）。最小 0（= 永不被维度随机抽中，但仍作为条目分组和 AI 自主的候选用）。
- **方向提示**：这个维度的事件是什么气质。维度随机和 AI 自主都会把整段喂给模型当方向。

### 2.3 维度在管线里的四个作用

1. 维度随机板块的方向池（按权重加权抽）；
2. AI 自主板块的候选清单（模型只能从启用维度里挑）；
3. 条目的分组归属（维度停用 → 其条目全部出局）；
4. 密度规则的单位（同维度连出两次 → 暂停一轮，三个板块都遵守）。

### 2.4 默认五维度（可随意改）

| 维度 | 默认权重 | 气质 |
|---|---|---|
| 顺向 | 1 | 意外之喜、被善意注视；以轻为主，让世界有温度，不扭转剧情 |
| 机会 | 1 | 临时邀约、竞争性小游戏、被认可；给 user 一个可拉可不拉的新选项 |
| 环境 | 1 | 天气突变、设施故障、场所自带事件、他人求助；改变舞台而不针对主角 |
| 摩擦 | 1.2 | 曝光被识别、舆情发酵、小意外、过去浮现、群体内部摩擦；会发酵，但出口必须存在 |
| 关系与旧事 | 1 | 旧识出现、旧情旧怨被提起、关系微妙变化 |

## 3. 事件条目（设置区折叠板块）

### 3.1 每行信息

启用勾选框 + 条目名；信息行依次为：`维度 X · 轻/重 · 概率 N% · 权重 N · 冷却 N 层（剩 M 层）· 关键词 …`；收起时还有方向提示前 70 字。

### 3.2 编辑器逐字段

| 字段 | 含义 |
|---|---|
| 条目名 | 即时保存 |
| 维度 | 下拉选；选「未分组」= 不参与掷骰 |
| 轻重 | 见 3.3 |
| 触发概率 | 0–1，步进 0.05。与权重相乘参与抽取，值越大越容易被掷中 |
| 权重 | 与概率相乘决定抽中占比 |
| 冷却层数 | 掷中后多少层内不再入选；0 = 不限 |
| 触发关键词 | 逗号 / 顿号 / 分号分隔，支持中英文标点；留空 = 不限 |
| 方向提示 | 给模型的一句话：触发情境与张力方向 |

### 3.3 四个容易误解的点

- **概率和权重分工**：两者相乘决定条目板块里谁被抽中——概率放大命中机会，权重在同概率下再加成；掷骰必定抽出一条，不存在「概率未中、空手而归」。
- **冷却按掷中楼层起算**：显示「剩 M 层」实时更新；自由生成不消耗任何条目的冷却，但受「最近事件防重复」约束。
- **触发关键词**：命中文本 = 最近 N 层对话（N=设置页「检索扫描层数」，默认 20，0=全部；已隐藏楼层不参与；英文不区分大小写）。填了但没命中 → 该条目本轮无资格。
- **轻重不影响掷骰概率**：它只影响三处——生成提示词的执行口径（轻=一根针，点到即止不自带走向；重=一个局，不处理会发酵但出口必须存在）、AI 建库导入时的默认数值（重：概率 0.15/冷却 40；轻：概率 0.2/冷却 20）、界面显示。

新建条目默认值：概率 0.2 / 权重 1 / 冷却 20 / 挂第一个维度 / 轻。

## 4. AI 建库（独立折叠区，不参与掷骰）

### 4.1 输入与生成

- **维度**：下拉选（含停用的维度）。
- **数量**：1–10，默认 5。
- **补充说明**：可选，写想要的题材、烈度、要避开什么（例：「偏日常向，不要涉及警察；重事件占一半」）。
- **生成条目草稿** → 一次规划通道调用。模型要求：贴维度气质、轻重搭配宁重不轻、条目名 2–6 字、方向提示 30–60 字、不与现有条目重复（现有全部条目名都会喂给它避重）。

### 4.2 草稿预览与导入

- 每行：勾选框（默认全勾）+ 轻/重下拉 + 「条目名：方向提示」。
- **导入勾选项**：并入事件库，挂在所选维度上，数值用轻重默认（见 3.3），导入后可在条目编辑器里逐条调。导入本身不花调用。
- **清空草稿**：丢弃本次预览。

### 4.3 注意

模型偶尔会不听话：名字过长会被截到 20 字、提示截到 120 字；完全没返回可用条目会弹提示，换措辞再试即可。

## 5. 路人反应（第 1 步「路人反应」入口键 → 悬浮面板）

### 5.1 定位：给主对话模型的「口径」，不是替它写好的正文

主对话模型处理路人反应常走两个极端：要么每层都「全场哗然」地重复渲染，要么一笔带过之后世界集体失忆。这个工具把「刚发生的引人注目的事」交给规划通道，产出一张**有边界、会自动退场**的反应单元，注入后由它约束主对话模型。

单元只定**身份、形式、烈度与边界**（什么人会注意到、以什么动作或低语反应、消息传不传开），具体台词、镜头、人选由主对话模型当轮就地呈现——提示词里为此定了铁律：反应织进当前场景，不切镜头到不在场的人、不写路人内心戏、不虚构具体路人再跟进他们事后做了什么。

它和剧情规划是协同的：生成反应单元用的材料＝**第 1 步确认的同一套**（随机事件 / 路人反应 / 规划三个功能共用一套材料模板，只有任务指令各是各的）；转隐身注入生效后，规划分析与检查报告又会自动附带同一份口径——先出反应、再带着它做规划，两步看到同一个世界。**已生效的注入不会自动进工具生成**（防同文双算），跨工具影响只走显式导入。

### 5.2 面板内容

- **指导意见**（可空）：期望烈度、余波方向、要避开什么。
- **生成反应卡** → 一次规划通道调用（引人注目的事由模型从最近对话里自己认出），产物为反应单元入暂存池（≤3，满了禁生成、先删一个）。
- **导入随机事件单元做参考**：对方暂存里「加工史还没本工具」的才能勾（同工具回流禁、两标满禁）；**导入不消耗**——原单元留在事件暂存，可再生成重 roll、可自己注入；导入产物＝带累积徽章的新单元（左＝事件、右＝反应）。
- **清空暂存**：只清路人反应名下的单元（随机事件的不动；已转隐身注入的不受影响）。
- 反应单元卡：显著性星级、即时口径、余波口径、底线、楼层预算、注入正文都可就地编辑；**转隐身注入与第 1 步「插入单元」勾选两路互斥**——转注入即自动取消勾选（规划与检查经生效注入自动附带同一口径，再勾就是同文进两次），勾选中的则留在材料里随分析发送。采纳规划不清池，单元跨轮留在暂存里复用。

### 5.3 反应单元的五个部分

| 部分 | 说明 |
|---|---|
| 显著性 1–5 | 1=只有身边几人注意到；3=在场者普遍反应；5=全场围观且会留下记录。星标显示 |
| 即时反应口径 | 每轮 1-3 句的量：什么身份的旁观者、以什么动作或低语反应、烈度如何。写身份与形式，不写现成台词与画面；写一次就够 |
| 余波口径 | 消息传开/平息的**方向**：显著性 1–3 是不外传（在场者议论几句后自然平息）；4–5 是传播走向（经什么渠道传开、到多大范围、后续场景里陌生人以什么形式提起），贴世界观——现代用拍摄上传/本地群/热搜边缘，古风奇幻用口耳相传/悬赏告示/教会官府 |
| 底线 | 不可逆伤害一律禁止（感情实质破裂、主要角色受异性实质侵犯、user 无法逆转的损失）；危机可重、出口必须存在；并列出本事件可接受的余波 |
| 楼层预算 | 有效层数，**一层 = 一条角色回复（user 消息不计）**。模型按显著性给：1–2 级取 2–4，3 级取 4–8，4 级取 10–18，5 级取 16–30（可手改 2–30），到期自动撤下 |

> 为什么没有「按楼层分段的扩散链」了：三四个楼层根本扩散不开——消息传开是以十条回复计的长过程，分段链条在短窗口里只会逼出镜头硬切和路人内心戏（上一版的实际问题）。新卡把扩散浓缩成一段「余波口径」，跨多层的演化交给进行中剧情/规划去管；旧版扩散链卡片还留在生效中的注入里，会继续按原样逐层换段直到到期。

### 5.4 确认注入后的自动行为（时间线）

1. **确认时**：注入 `0/N 层`，正文 = 头部（显著性、第 1/N 层）+ 原则声明（这件事已经发生；反应不是剧情，路人是背景；user 主动追问不算新触发）+ 即时反应口径 + 余波口径 + 底线 + 密度约束（同时最多 2 条事件线；重事件后 2-3 层只出轻的；user 处理期间不叠加；已发生的不复现）。
2. **楼层按「聊天楼层净增」推进**：注入时记下当时的角色回复楼数（基线），已过层数 = 当前楼数 − 基线。**滑动 / 重新生成只是替换最后一条回复，楼数不变、不消耗层数**；删楼层楼数只减、推导不为负。新卡正文口径不变，只有头部层数走；旧版扩散链卡会按楼层自动换段——**都是本地完成，不花调用**。
3. **最后 2 层**：正文尾部自动加「让反应自然收束（议论平息、注意力转移），不要开新枝」。
4. **到期**：注入自动停用撤下，弹 toastr「路人反应注入『xx』已到期自动撤下」。注入正文里写明了到期后世界回归常态、除非 user 主动提起——所以退场后模型也不会突然失忆式硬切。

绑定关系：仅当前聊天（切到别的聊天时它不注入，回来继续按原楼层走）。

### 5.5 手改正文会怎样

单元卡上有「注入正文」文本框，可自由改。**改过一次** → 冻结为你写的文本，只按层数到期（底线、密度约束等如果还想要就写进去）。「楼层预算」改动时，若没动过正文，预览会按新预算重新生成。

### 5.6 在哪里查看与提前撤下

剧情指导页底部工具区的「生效中的隐身注入」折叠区里（游戏玩法折叠区下方），来源显示「路人反应」，带 `X/N 层` 进度，可停用或直接删除（停用后层数不再推进）。

## 6. 计费：哪些操作花规划通道调用

| 操作 | 调用次数 |
|---|---|
| 掷骰未掷出（所有维度被停用 / 板块全没勾或没货）；空聊天直接拦截 | 0 |
| 掷骰掷出（三板块任一，含 AI 自主挑维度）/ 大模型随机 | 1 |
| AI 建库「生成条目草稿」 | 1（导入不花） |
| 路人反应「生成反应卡」 | 1 |
| 立为单元（草稿入池 / 意见立卡）/ 跨工具导入 / 第 1 步勾「插入单元」/ 换段 / 到期撤下 | 0（本地完成） |

所有调用走插件自配的独立 API，不占主对话连接。掷骰与大模型随机只在随机事件工具面板操作（唯一入口），「参考事件库」勾选就在面板顶部；「事件库设置 / AI 建库」在剧情指导页底部，管库不管掷。

## 7. 注意事项与边界

- **全局 vs 单聊天**：维度、条目、掷骰板块开关与权重、最近事件列表都是**全局**的（跟扩展设置走，所有聊天共享）；两工具的**单元暂存池**、随机事件的生成草稿、事件转注入和路人反应注入是**仅当前聊天**的（跟聊天走，跨聊天不带走，意见草稿与「参考事件库」开关也随聊天存）。
- **冷却与最近事件跨聊天共账**：冷却楼层和最近列表不分聊天。只在一个聊天里玩时无感；多聊天并用同一套事件库时，A 聊天刚掷中的条目在 B 聊天也处于冷却。
- **导入规则只有一条**：只能导入「加工史里还没有本工具」的单元——同工具回流禁、两标满禁，套娃在结构上不可能；导入不消耗，原单元留在对方暂存。
- **未分组条目不参与掷骰**；删维度不删条目。
- **停用维度** = 它的条目一起出局 + 自由生成不抽它。
- **已隐藏楼层**不进任何上下文（对话、关键词扫描、世界书扫描）。
- 反应卡正文里已内置你的 NPC_Reaction 密度规则；如果某张卡的表现不合预期，用「指导意见」告诉模型往哪边修，比改代码快。
