# 随机事件页 · 使用说明书

对应版本：随机事件页布局改版（常用动作置顶、事件库配置折叠进底部设置区、板块开关、移除「余波写入记忆表格」）。界面文案以扩展实际显示为准，本文解释每个部分的含义与行为。

## 0. 这一页是什么

页面分成两部分：**上面是常用的两个动作**，**底部是折叠起来的「事件库设置」**。

常用动作（一直显示）：

| 动作 | 一句话定位 |
|---|---|
| 掷骰生成事件 | 出事件的入口：一条管线决定「这次出什么、往哪个方向出」 |
| 路人反应校准 | 另一种东西：不产新事件，而是教主对话模型「世界如何回应刚发生的事」，走隐身注入生效 |

「事件库设置」折叠区（底部，默认收起）：

| 板块 | 一句话定位 |
|---|---|
| 事件维度 | 骨架：事件分成哪几类；自由生成时按维度加权抽方向 |
| 事件条目 | 血肉：具体的事件库，每条带概率 / 权重 / 冷却 / 轻重 / 触发关键词 |
| AI 建库 | 填库工具：让模型按维度批量出条目草稿，勾选后导入 |

折叠区顶部有**板块开关**（三个勾选框：事件维度 / 事件条目 / AI 建库），不勾的板块直接从这里消失；关闭「事件条目」还有实际作用——掷骰不再走事件库，全部按维度即兴。三个板块各自也是折叠的，默认收起。

维度、条目、AI 建库合起来是「三层结构」：维度层 → 条目层 → 掷骰管线。路人反应是反应性校准，和随机事件互补：随机事件是「主动制造的意外」，路人反应是「已有行动的后果校准」。

## 1. 掷骰生成事件（第一区）

### 1.1 事件库占比（%）

- 位置在底部「事件库设置 → 事件条目」里（布局改版后从掷骰区挪了过去）。数字输入框，0–100，默认 60，改动即保存。
- 含义：每次掷骰，有多大比例的次数走「事件库抽条目」，其余次数走「按维度加权自由生成」。
- 100 = 只抽库（库全被过滤掉时会自动落到自由生成）；0 = 每次都自由生成（事件库形同虚设，但密度规则、防重复仍然生效）。

### 1.2 掷骰按钮按下后的完整流程

1. **维度检查**：一个启用的维度都没有 → 直接提示「本次未掷出事件（没有启用的维度）」，不花任何调用。
2. **密度规则**：查看最近两次掷骰记录，若都是同一维度，本次掷骰暂停该维度（库内条目和自由生成都避开它）；没有别的维度可选时忽略此规则。
3. **条目过滤**（候选资格）：条目启用 + 所属维度启用 + 不在冷却中 + 触发关键词命中（若填了关键词）。
4. **决定走库还是自由**：有合格条目、且随机数落在「事件库占比」内 → 走库；否则走自由生成。
5. **走库**：合格条目各自按「触发概率」过筛，一个没中 → 「本次未掷出事件（条目概率未中）」，不花调用；有中的按「权重」加权抽一条。
6. **走自由**：在启用维度里按「维度权重」加权抽一个方向，让模型按该维度的气质即兴。
7. **生成调用**（一次规划通道调用）：上下文 = 角色设定摘要 + 最近对话（设置页「规划携带层数」，默认 30，0=全部；已隐藏楼层不计入）+ 世界书命中（按设置页「检索扫描层数」扫描）+ 最近出过的事件标题（防重复）+ 底线条款 + 事件方向（库内：维度/条目名/方向提示/轻重口径；自由：维度名 + 方向提示）。
8. **落账**：生成成功后才记账——库内条目从当前楼层起算冷却；写入「最近事件」列表（最多 12 条）。生成失败不烧冷却。

### 1.3 状态行与事件卡

- 状态行会显示来源：「来自事件库『xxx』· 重/轻」或「来自维度『xx』自由生成」，或未掷出的原因。
- 事件卡：标题 + 描述 + 约 3 个可选走向。
  - **点一个走向** → 转为隐身注入：明盘、深度 4、system 角色、仅当前聊天、**20 层后自动过期**，然后自动跳到隐身注入页。
  - **不选走向**也完全可以：事件卡本身只是给你看的参考，不注入不产生任何后续。

## 2. 事件维度（设置区折叠板块）

### 2.1 每行控件

- **启用**：取消勾选 = 该维度整体下线（它的条目不参与掷骰，自由生成也不抽它）。
- **维度名**（加粗显示）。
- 概要行：权重数字 + 方向提示前 60 字。
- **编辑 / 收起**：展开编辑器。
- **垃圾桶**：删除维度。**条目不会被删**，只会变成「未分组」（未分组条目不参与掷骰，可在条目编辑器里挂回其他维度）。

### 2.2 编辑器（展开后）

- **维度名**：即时保存。
- **权重**：自由生成时的抽中占比（和别的维度比）。最小 0（= 永不被自由生成抽中，但仍作为条目分组用）。
- **方向提示**：这个维度的事件是什么气质。自由生成时整段喂给模型当方向。

### 2.3 维度在管线里的三个作用

1. 自由生成的方向池（按权重加权抽）；
2. 条目的分组归属（维度停用 → 其条目全部出局）；
3. 密度规则的单位（同维度连出两次 → 暂停一轮）。

### 2.4 默认五维度（可随意改）

| 维度 | 默认权重 | 气质 |
|---|---|---|
| 顺向 | 1 | 意外之喜、被善意注视；以轻为主，让世界有温度，不扭转剧情 |
| 机会 | 1 | 临时邀约、竞争性小游戏、被认可；给 user 一个可拉可不拉的新选项 |
| 环境 | 1 | 天气突变、设施故障、场所自带事件、他人求助；改变舞台而不针对主角 |
| 摩擦 | 1.2 | 曝光被识别、舆情发酵、小意外、过去浮现、群体内部摩擦；会发酵，但出口必须存在 |
| 关系与旧事 | 1 | 旧识出现、旧情旧怨被提起、关系微妙变化 |

## 3. 事件条目（设置区折叠板块）

### 3.1 每行信息

启用勾选框 + 条目名；信息行依次为：`维度 X · 轻/重 · 概率 N% · 权重 N · 冷却 N 层（剩 M 层）· 关键词 …`；收起时还有方向提示前 70 字。

### 3.2 编辑器逐字段

| 字段 | 含义 |
|---|---|
| 条目名 | 即时保存 |
| 维度 | 下拉选；选「未分组」= 不参与掷骰 |
| 轻重 | 见 3.3 |
| 触发概率 | 0–1，步进 0.05。走库时每条合格条目按它过筛 |
| 权重 | 过筛后的候选池内，按它加权抽一 |
| 冷却层数 | 掷中后多少层内不再入选；0 = 不限 |
| 触发关键词 | 逗号 / 顿号 / 分号分隔，支持中英文标点；留空 = 不限 |
| 方向提示 | 给模型的一句话：触发情境与张力方向 |

### 3.3 四个容易误解的点

- **概率和权重分工**：概率决定「进不进候选池」（每条独立过筛，可能全灭），权重只决定「池内谁被抽中」。
- **冷却按掷中楼层起算**：显示「剩 M 层」实时更新；自由生成不消耗任何条目的冷却，但受「最近事件防重复」约束。
- **触发关键词**：命中文本 = 最近 N 层对话（N=设置页「检索扫描层数」，默认 20，0=全部；已隐藏楼层不参与；英文不区分大小写）。填了但没命中 → 该条目本轮无资格。
- **轻重不影响掷骰概率**：它只影响三处——生成提示词的执行口径（轻=一根针，点到即止不自带走向；重=一个局，不处理会发酵但出口必须存在）、AI 建库导入时的默认数值（重：概率 0.15/冷却 40；轻：概率 0.2/冷却 20）、界面显示。

新建条目默认值：概率 0.2 / 权重 1 / 冷却 20 / 挂第一个维度 / 轻。

## 4. AI 建库（设置区折叠板块）

### 4.1 输入与生成

- **维度**：下拉选（含停用的维度）。
- **数量**：1–10，默认 5。
- **补充说明**：可选，写想要的题材、烈度、要避开什么（例：「偏日常向，不要涉及警察；重事件占一半」）。
- **生成条目草稿** → 一次规划通道调用。模型要求：贴维度气质、轻重搭配宁重不轻、条目名 2–6 字、方向提示 30–60 字、不与现有条目重复（现有全部条目名都会喂给它避重）。

### 4.2 草稿预览与导入

- 每行：勾选框（默认全勾）+ 轻/重下拉 + 「条目名：方向提示」。
- **导入勾选项**：并入事件库，挂在所选维度上，数值用轻重默认（见 3.3），导入后可在条目编辑器里逐条调。导入本身不花调用。
- **清空草稿**：丢弃本次预览。

### 4.3 注意

模型偶尔会不听话：名字过长会被截到 20 字、提示截到 120 字；完全没返回可用条目会弹提示，换措辞再试即可。

## 5. 路人反应校准（置顶常用动作）

### 5.1 适用场景

主对话模型处理路人反应常走两个极端：要么每层都「全场哗然」地重复渲染，要么一笔带过之后世界集体失忆。这个区块把「刚发生的引人注目的事」交给规划通道，产出一张**有边界、会随楼层演化、会自动退场**的反应卡，注入后由它替你约束主对话模型。

### 5.2 输入

- **刚发生了什么引人注目的事**：可空。空着则模型从最近对话里自己找；实在找不到就按「日常被注视」处理（显著性取 1）。
- **补充说明**：可空。期望烈度、扩散方向、要避开什么。

**生成反应卡** → 一次规划通道调用。

### 5.3 反应卡的五个部分

| 部分 | 说明 |
|---|---|
| 显著性 1–5 | 1=只有身边几人注意到；3=在场者普遍反应；5=全场围观且会留下记录。星标显示 |
| 即时反应写法 | 每轮 1–3 句的具象指导（谁在看、低语什么、让路、举起手机又放下……），瞩目型优先于互动型，身份符合场景。写一次就够，不用每层重写 |
| 扩散链 | 按楼层分段的世界反应（例：第 1-2 层围观拍摄 → 第 3-5 层本地群转发 → 第 6+ 层热搜边缘/官方介入），贴当前世界观：现代用拍摄上传/热搜/官方，古风奇幻用口耳相传/悬赏/教会 |
| 底线 | 不可逆伤害一律禁止（感情实质破裂、主要角色受异性实质侵犯、user 无法逆转的损失）；危机可重、出口必须存在；并列出本事件可接受的余波 |
| 楼层预算 | 有效层数（模型按显著性给 4–12，可手改 2–30），到期自动撤下 |

### 5.4 确认注入后的自动行为（时间线）

以预算 8 层、扩散链 1-2 / 3-5 / 6+ 为例：

1. **确认时**：注入 `0/8 层`，正文 = 头部（显著性、第 1/8 层）+ 原则声明（这件事已经发生；反应不是剧情，路人是背景；user 主动追问不算新触发）+ 即时反应写法 + **当前扩散段（第 1-2 层内容）** + 底线 + 密度约束（同时最多 2 条事件线；重事件后 2-3 层只出轻的；user 处理期间不叠加；已发生的不复现）。
2. **每收到一条 AI 回复**：层数 +1。正文里的扩散段自动切换（第 3 层起换 3-5 段，第 6 层起换 6+ 段），头部层数同步走。**换段是本地完成的，不花调用。**
3. **最后 2 层**：正文尾部自动加「让反应自然收束（议论平息、注意力转移），不要开新枝」。
4. **到期**：注入自动停用撤下，弹 toastr「路人反应注入『xx』已到期自动撤下」。注入正文里写明了到期后世界回归常态、除非 user 主动提起——所以退场后模型也不会突然失忆式硬切。

绑定关系：仅当前聊天（切到别的聊天时它不注入，回来继续按原楼层走）。

### 5.5 手改正文会怎样

卡片预览底部有「注入正文预览」文本框，可自由改。**没改过** → 按楼层自动换段；**改过一次** → 冻结为你写的文本，不再换段（底线、密度约束等如果还想要就写进去），但「N 层后自动撤下」照常执行。另外改「楼层预算」时，若没动过正文，预览会自动按新预算重新生成。

### 5.6 在隐身注入页怎么认出它

注入列表里来源显示「路人反应（显著性 X/5，逐层衰减）」，并带 `X/N 层` 进度。顺带：该页「新建明盘注入」现在也能直接选「N 层后自动撤下」。

## 6. 计费：哪些操作花规划通道调用

| 操作 | 调用次数 |
|---|---|
| 掷骰未掷出（无维度 / 概率全灭） | 0 |
| 掷骰掷中（库内或自由） | 1 |
| AI 建库「生成条目草稿」 | 1（导入不花） |
| 路人反应「生成反应卡」 | 1 |
| 反应注入换段 / 到期撤下 | 0（本地完成） |

所有调用走插件自配的独立 API，不占主对话连接。剧情指导向导第 2 步的「掷骰（库/自由）」用的是同一条管线、同一本账（冷却与最近事件互相通用）。

## 7. 注意事项与边界

- **全局 vs 单聊天**：维度、条目、占比、最近事件列表都是**全局**的（跟扩展设置走，所有聊天共享）；事件转注入和路人反应注入是**仅当前聊天**的。
- **冷却与最近事件跨聊天共账**：冷却楼层和最近列表不分聊天。只在一个聊天里玩时无感；多聊天并用同一套事件库时，A 聊天刚掷中的条目在 B 聊天也处于冷却。
- **未分组条目不参与掷骰**；删维度不删条目。
- **停用维度** = 它的条目一起出局 + 自由生成不抽它。
- **已隐藏楼层**不进任何上下文（对话、关键词扫描、世界书扫描）。
- 反应卡正文里已内置你的 NPC_Reaction 密度规则；如果某张卡的表现不合预期，用「补充说明」告诉模型往哪边修，比改代码快。
